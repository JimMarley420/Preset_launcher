À propos de PresetLauncher

Un logiciel Windows indépendant développé par Jimmy Marley.

Le projet

PresetLauncher regroupe les programmes en presets pour les tâches récurrentes. Il est développé en C# avec .NET et WinUI 3 et distribué sous licence MIT.

GitHub

Données et confidentialité

L’application stocke ses données localement et contacte GitHub pour les mises à jour. Aucun compte n’est nécessaire. Ce site n’utilise ni analytics ni cookies. La préférence de thème est enregistrée localement dans le navigateur. Les téléchargements sont hébergés sur GitHub.

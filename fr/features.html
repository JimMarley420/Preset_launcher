Fonctionnalités

Lancement de programmes, historique et données locales dans une application Windows native.

Presets et lancement

Les presets regroupent applications, raccourcis, scripts et processus en cours. Le lancement complet respecte l’ordre et les délais configurés ; le mode partiel ne lance que les programmes non détectés. Les droits administrateur peuvent être demandés par programme.

La fermeture des processus correspondants nécessite une confirmation et peut forcer leur arrêt. Les modifications non enregistrées peuvent être perdues.

Historique

Les lancements complets sont enregistrés avec les résultats et les erreurs. Le mode partiel n’ajoute pas d’entrée à l’historique.

Statistiques

Les statistiques présentent les lancements enregistrés et les programmes les plus utilisés.

Paramètres et données

Thèmes clair, sombre et système, Mica ou Acrylic selon Windows, interface anglaise ou française. Les sauvegardes JSON, la restauration, la vérification des chemins manquants et la réinitialisation sont accessibles dans les paramètres.

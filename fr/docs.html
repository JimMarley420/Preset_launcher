Prise en main

Les presets sont composés de programmes installés localement. L’éditeur permet de régler l’ordre de lancement, les délais et les droits administrateur.

Lancer plusieurs applications en un clic

Exemples : Steam et Discord pour le gaming ; Visual Studio Code et Windows Terminal pour le développement ; OBS Studio et les outils de diffusion pour le streaming. Les presets référencent des raccourcis et exécutables locaux.

Le lancement complet respecte l’ordre et les délais configurés. Un délai ne constitue pas une vérification de la disponibilité du programme.

Le mode partiel évite de relancer les programmes détectés comme déjà ouverts.

Questions fréquentes

PresetLauncher est-il gratuit ?

Oui. Le code est public sous licence MIT.

Faut-il écrire un script batch ?

Non. L’éditeur de presets prend en charge les applications, raccourcis et scripts.

Les positions des fenêtres sont-elles restaurées ?

Non. PresetLauncher gère le lancement de programmes, pas la disposition des fenêtres.

Peut-on transférer ses presets sur un autre PC ?

Les données peuvent être transférées par export et import JSON. Les programmes doivent être installés séparément, avec des chemins valides sur le PC de destination.

Données et sauvegardes

Les données sont normalement stockées dans %LocalAppData%\PresetLauncher\data.json. Les sauvegardes JSON ne sont pas chiffrées et ne contiennent pas les programmes installés. Les presets importés doivent provenir de sources fiables et leurs chemins doivent être vérifiés avant exécution.

Mises à jour

Le système de mise à jour vérifie un manifeste signé, la taille et l’empreinte SHA-256 de l’installateur. Les mises à jour facultatives peuvent être ignorées, celles recommandées reportées de 24 heures et celles obligatoires doivent être installées.

Dépannage

Les erreurs de lancement peuvent provenir de chemins invalides ou de permissions insuffisantes. Les rapports de bugs incluent les versions de PresetLauncher et de Windows ainsi que les étapes de reproduction.

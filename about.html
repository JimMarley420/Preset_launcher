About PresetLauncher

An independent Windows application by Jimmy Marley.

The project

PresetLauncher groups programs into presets for recurring tasks. It is written in C# with .NET and WinUI 3 and distributed under the MIT license.

GitHub

Data and privacy

The application stores its data locally and contacts GitHub to check for updates. No account is required. This site does not use analytics or cookies. The theme preference is stored locally in the browser. Downloads are hosted on GitHub.

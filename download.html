Features

System requirements

A Microsoft-supported Windows version is required. The installer requires build 17763 or later. The application targets build 19041. .NET and Windows App SDK runtimes are bundled.

System type: Settings → System → About.

Verify your download

Installers are not Authenticode-signed. Windows SmartScreen may display a warning. The published SHA-256 checksums allow verification of installer integrity.

Get-FileHash .\PresetLauncher_Setup_<version>.exe -Algorithm SHA256

Changing architecture requires uninstalling the existing copy first. Application data is retained; a backup is recommended.

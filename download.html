System requirements

Use a Microsoft-supported Windows version. The installer requires build 17763 or later. The application targets build 19041. .NET and Windows App SDK runtimes are bundled.

Find your architecture in Settings → System → About → System type.

Verify your download

Installers are not Authenticode-signed. Windows SmartScreen may display a warning. Verify the source and compare the file hash with the published SHA-256 checksums.

Get-FileHash .\PresetLauncher_Setup_<version>.exe -Algorithm SHA256

To switch architecture, uninstall the existing copy before installing the other architecture. Your data is retained; make a backup first.

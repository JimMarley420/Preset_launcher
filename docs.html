Getting started

Presets contain locally installed programs. The editor provides controls for launch order, delays and administrator privileges.

Launch multiple apps in one click

Example combinations include Steam and Discord for gaming, Visual Studio Code and Windows Terminal for development, and OBS Studio alongside other streaming tools. Presets reference local shortcuts and executables.

Full launch mode respects the configured order and delays. A delay does not establish that a program is ready.

Missing-only launch skips programs detected as already running.

Frequently asked questions

Is PresetLauncher free?

Yes. The source code is public under the MIT license.

Do I need to write a batch script?

No. The preset editor supports applications, shortcuts and scripts.

Does it restore window positions?

No. PresetLauncher manages program launching, not window layouts.

Can I move my presets to another PC?

JSON export and import support data transfer between PCs. Programs must be installed separately, with valid paths on the destination PC.

Data and backups

Data is normally stored in %LocalAppData%\PresetLauncher\data.json. JSON backups are not encrypted and do not contain installed programs. Imported presets should come from trusted sources and their paths should be verified before execution.

Updates

The updater verifies a signed manifest, installer size and SHA-256. Optional updates can be skipped, recommended updates can be deferred for 24 hours, and required updates must be installed.

Troubleshooting

Launch failures may result from invalid executable paths or insufficient permissions. Bug reports include the application version, Windows version and reproduction steps.

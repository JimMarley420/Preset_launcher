Getting started

Install the correct architecture, create a preset and add programs. Use the arrows to set their launch order and the gear icon to set options.

Launch multiple apps in one click

Create a Gaming preset with Steam and Discord, or a Development preset with Visual Studio Code and Windows Terminal. For streaming, group OBS Studio with the other tools you use during a live stream. Add your own installed shortcuts or executables.

Arrange the programs in the order you want. In full launch mode, set individual delays if one tool needs to start before another. A delay does not guarantee that a program is ready.

Use Launch missing only to resume an activity without restarting programs detected as already running.

Frequently asked questions

Is PresetLauncher free?

Yes. The source code is public under the MIT license.

Do I need to write a batch script?

No. Create groups in the interface and add applications, shortcuts and scripts.

Does it restore window positions?

No. PresetLauncher manages program launching, not window layouts.

Can I move my presets to another PC?

Export your data as JSON, then import it on the other PC. Install the programs separately and check their paths before launching a preset.

Data and backups

Data is normally stored in %LocalAppData%\PresetLauncher\data.json. JSON backups are not encrypted and do not contain installed programs. Inspect imported presets before use.

Updates

The updater verifies a signed manifest, installer size and SHA-256. Optional updates can be skipped, recommended updates can be deferred for 24 hours, and required updates must be installed.

Troubleshooting

Check executable paths and permissions if a program fails to start. Report reproducible problems with the application version and Windows version.
